# Resolving-Security-Alerts-Using-a-Playbook

I am a level-one security operations center (SOC) analyst at a financial services company. Previously, I received a phishing alert about a suspicious file being downloaded on an employee's computer. After investigating the email attachment file's hash, the attachment has already been verified as malicious.
My organization's security policies and procedures describe how to respond to specific alerts, including what to do when you receive a phishing alert.
